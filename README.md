# Reflection on Programming for Data Science Assignment

## Part 1: Basic Python
In this part, I learned how to handle data without high-level libraries like Pandas. Implementing CSV parsing and statistical functions (min, max, median) using only built-in Python features reinforced my understanding of:
- File I/O operations and string manipulation.
- Data structures like lists and dictionaries.
- The logic behind common statistical measures and how to handle missing data ('-') manually.

## Part 2: Data Science Investigation
This part demonstrated the power of the Python Data Science ecosystem (Pandas, Matplotlib, Seaborn, SciPy). Key learnings included:
- **Data Integration**: Merging datasets on a common key (timestamp).
- **Exploration**: Using visualizations to uncover temporal and environmental patterns in bike sharing.
- **Data Cleaning**: Applying the Interquartile Range (IQR) method to identify and remove outliers that could bias results.
- **Statistical Validation**: Formulating hypotheses and using t-tests to determine if observed differences (like weekday vs weekend usage) are statistically significant.

Overall, the assignment provided a comprehensive overview of the full data pipeline, from raw data extraction to statistical inference.

## Part 4: Use of Git
This project was developed using Git for version control. Key practices included:
- Initializing a local repository.
- Staging and committing changes with descriptive messages.
- Tracking the evolution of Jupyter notebooks and analysis results.
